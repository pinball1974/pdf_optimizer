# pdfopt — 스캔한 책 PDF를 태블릿 독서용으로 최적화

자동급지 스캐너로 스캔한 책 PDF의 고질적인 문제를 해결하는 CLI 도구:

- **기울기 보정(디스큐)** — 급지 중 종이가 서서히 회전해 생기는 *페이지 내 각도
  드리프트*(상단과 하단 줄이 평행하지 않은 문제)까지 보정. 줄별 각도를
  `θ(y) = a + b·y`로 피팅한 뒤 픽셀별 변위 리매핑으로 모든 줄을 동시에 수평화.
- **고정폭 중앙 정렬** — 전 페이지의 본문 칼럼 폭을 측정해 최대 폭 + 좌우 5%
  여백의 통일 캔버스를 만들고, 각 페이지의 본문 칼럼 중심을 캔버스 중앙에 배치.
  홀/짝 페이지의 제본 여백 차이가 사라져 세로 스크롤 시 시선이 흔들리지 않음.
- **상하 여백 크롭** — 책 전체의 공통 상하 여백을 제거(모든 페이지 동일한 이동량
  적용 → 페이지 간 세로 리듬 유지). 페이지번호·각주는 원래 위치에 보존.
- **뒷비침 제거 (적응형)** — 배경에 가까운 밝은 회색만 흰색으로 눌러 뒷면 글자
  비침 제거. 인쇄가 연한 책은 페이지별 잉크 밝기를 측정해 제거 강도를 자동으로
  완화하므로 가는 획이 침식되지 않음.
- **검색 가능한 OCR 레이어** — Apple Vision(macOS 내장, 로컬 처리)으로 한글을
  인식해 보이지 않는 텍스트 레이어 삽입. 러닝 헤더·페이지 번호 같은 반복
  요소는 **책 전체에서 같은 텍스트가 고정 위치에 반복되는지**로 탐지해
  제외하므로, "364 책제목"처럼 번호와 제목이 붙은 푸터도 걸러지고 챕터 첫
  페이지의 진짜 제목은 보존됨.
- **단락 복원 TXT 동시 저장** — OCR 결과에서 조판 기하(들여쓰기·행 간격·짧은
  마지막 행)로 단락 경계를 판정해, 문장/단락 내 강제 개행을 제거한
  `<원본이름>.txt`를 출력 PDF와 같은 폴더에 저장. 일러스트 페이지를 사이에 둔
  문단 연결, 구두점 경계 공백 복원, 오인식 숫자 노이즈 제거 포함 (`--no-txt`로
  생략 가능).
- 일러스트/표지/목차 페이지는 자동 감지해 기울기 보정을 건너뛰고 콘텐츠 기준
  중앙 배치.

## 요구 사항

- **macOS** — OCR 텍스트 레이어가 macOS 내장 Apple Vision을 사용한다.
  다른 OS에서도 기하 보정(기울기·여백·판형)은 동작하며, OCR만 자동으로
  생략된다.
- **Python 3.11 이상** (3.13에서 개발·테스트됨). 없다면 Homebrew로:

  ```bash
  brew install python@3.13
  ```

## 설치

```bash
# 1. 저장소 받기
git clone https://github.com/pinball1974/pdf_optimizer.git
cd pdf_optimizer

# 2. 가상환경 생성
python3.13 -m venv venv

# 3. 패키지 설치 (의존성 포함: pymupdf, opencv, numpy, pyobjc-Vision)
venv/bin/pip install -e .
```

설치 확인:

```bash
venv/bin/pdfopt --help
```

## 실행

설치하면 `pdfopt` 명령이 생겨 **어느 폴더에서든** 실행할 수 있다.
가상환경을 활성화(`source venv/bin/activate`)했다면 `pdfopt`만 치면 되고,
활성화 없이 쓰려면 `<프로젝트 경로>/venv/bin/pdfopt`로 부르면 된다.

변환할 PDF는 아무 폴더에 있어도 된다 — 파일 경로를 인자로 넘기면 되고,
결과물은 기본적으로 **입력 파일과 같은 폴더**에 생긴다. 경로에 공백이나
한글이 있으면 따옴표로 감싼다 (Finder에서 파일을 터미널 창으로 드래그하면
경로가 자동 입력된다).

**일반 책 (텍스트 위주)**:

```bash
pdfopt ~/Downloads/책.pdf
```

결과물 두 개가 입력 파일과 같은 폴더에 생긴다:

- `책_optimized.pdf` — 기울기 보정 + 고정폭 중앙정렬 + 뒷비침 제거 +
  검색 가능한 OCR 레이어가 들어간 PDF
- `책.txt` — 단락 내 강제 개행을 제거하고 문단 구조를 복원한 텍스트

**만화책**:

```bash
pdfopt ~/Downloads/만화.pdf --comic
```

`만화_optimized.pdf` 하나만 생성된다(만화 모드는 OCR·txt 기본 꺼짐).

**전체 변환 전에 일부 페이지로 미리 확인**:

```bash
pdfopt ~/Downloads/책.pdf --pages 40-45 -o /tmp/미리보기.pdf
```

`-o`로 출력 위치를 바꾸면 txt도 그 폴더에 생긴다.

**여러 권 한꺼번에 (배치)**:

```bash
pdfopt ~/scan/*.pdf                # 폴더의 PDF 전부 순차 변환
pdfopt 책1.pdf 책2.pdf --comic     # 명시적 여러 파일
```

파일명이 `_optimized.pdf`로 끝나는 결과물은 자동으로 건너뛰므로, 같은
폴더에서 `*.pdf`로 재실행해도 결과물을 다시 변환하지 않는다. 한 권이
실패해도 나머지는 계속 변환하고 마지막에 실패 목록을 요약한다
(`-o`는 단일 파일일 때만 사용 가능).

**자주 쓰는 조합**:

```bash
pdfopt 책.pdf --no-ocr             # OCR 없이 빠르게
pdfopt 책.pdf --jpeg-quality 90    # 화질 우선
pdfopt 만화.pdf --comic --ocr      # 만화 + 말풍선 검색
```

첫 실행 시 페이지 분석 결과가 `<입력>.analysis.json`에 캐시되므로, 옵션을
바꿔 재실행하면 1차 분석 패스를 건너뛰어 훨씬 빠르다(입력 PDF가 바뀌면
자동으로 다시 분석한다). 처리 속도는 Apple Silicon 기준 200쪽 책 한 권에
OCR 포함 30초 내외.

## 만화책 모드 (`--comic`)

만화는 그림이 페이지 가장자리까지 닿는 경우가 많아 본문 모드의 공격적인
여백 재구성을 쓰면 안 된다. `--comic`은 페이지 구도를 통째로 보존한다:

- 기울기를 텍스트 라인 대신 **판넬 테두리의 긴 수평/수직 직선**(Hough +
  엣지 픽셀 회귀로 서브픽셀 정밀화)으로 추정. 직선이 부족한 전면 일러스트
  페이지, 그리고 집중선·스피드선처럼 선분 각도가 흩어져 합의가 없는
  페이지(가중 MAD > 0.6°)는 회전하지 않음 — 방향성 있는 아트를 페이지
  기울기로 오인해 멀쩡한 페이지를 돌리는 것을 방지.
- 회전각은 **페이지 중앙 기준**: 급지 드리프트로 상/하단 각도가 다를 때
  선분 각도를 `θ(y)`로 피팅해 중앙 y의 값을 쓴다. 단일 회전으로 드리프트
  자체는 못 없애지만, 잔여 기울기를 상하 ±절반씩 분산시켜 최대 잔류를
  절반으로 줄인다.
- 회전 보정은 ±1.5°로 제한 — 그 이상 측정되면 오측정으로 보고 경고 후
  상한값만 적용해, 한 페이지 때문에 책 전체가 작아지는 것을 방지.
- 회전하면 모서리 쐐기를 없애기 위해 내접 사각형으로 잘라야 하는데, 그
  크기가 페이지마다 달라지므로 1차 패스에서 전 페이지의 내접 크기를 구해
  **가장 좁은 폭 × 가장 낮은 높이**를 책 전체의 통일 크기로 삼는다.
- 각 페이지의 초과분은 **여백이 더 많은 쪽부터** 잘라낸다(잉크 경계 측정).
  가장자리까지 그림이 찬 쪽은 보호되고, 테두리 폭이 일정하게 유지된다.
- 톤 보정은 기본 꺼짐(스크린톤 보호; `--knee`를 주면 활성화), OCR은 기본
  꺼짐(`--ocr`로 활성화), txt 추출 없음.

주요 옵션:

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o` | `<입력>_optimized.pdf` | 출력 경로 |
| `--pages` | 전체 | `5,10-12` 형식(1부터), 테스트용 부분 변환 |
| `--dpi` | 300 | 처리 해상도 |
| `--margin` | 0.05 | 본문 폭 대비 좌우 여백 비율 |
| `--jpeg-quality` | 82 | 출력 JPEG 품질 |
| `--comic` | | 만화책 모드 (위 참조) |
| `--no-ocr` | | OCR 텍스트 레이어 생략 |
| `--ocr` | | OCR 강제 활성화 (만화 모드용) |
| `--no-txt` | | 단락 복원 TXT 저장 생략 |
| `--no-clean` | | 뒷비침 제거 끄기 |
| `--knee` | `150,205` | 뒷비침 제거 강도(회색 레벨 k0,k1). 연한 인쇄에서는 잉크 밝기에 맞춰 자동 상향 |
| `--workers` | 코어-2 | 병렬 프로세스 수 |
| `--no-cache` | | `<입력>.analysis.json` 캐시 무시하고 새로 분석 |

분석 결과는 `<입력>.analysis.json`에 캐시되어 재실행 시 1차 패스를 건너뜀.

## 동작 원리

1. **분석 패스 (150dpi)** — 페이지마다 텍스트 라인을 검출해 본문 칼럼
   폭·위치, 줄별 각도, 콘텐츠 영역을 기록. 콘텐츠 영역은 라인 주변 성분만
   집계해 가장자리 스캔 찌꺼기가 통계를 오염시키지 않음.
2. **전역 통계** — 본문 최대 폭(고정폭 기준), 책 전체 공통 상하 콘텐츠 경계를
   산출해 통일 캔버스 크기 결정.
3. **변환 패스 (300dpi)** — 톤 보정 → 디스큐 → 캔버스 배치 → JPEG 인코딩 →
   Vision OCR. 페이지 병렬 처리. (톤 보정이 디스큐보다 먼저인 이유: 리샘플링
   보간으로 흐려진 가는 획을 니가 지워버리는 것을 막기 위해.)
4. **반복 장식 제거** — 전 페이지 OCR을 모아 러닝 헤더/푸터를 반복 탐지로
   판정하고 텍스트 레이어와 txt에서 제외.
5. **PDF 조립** — 페이지 이미지 + 보이지 않는 텍스트 레이어(`render_mode=3`,
   내장 한국어 폰트, 단어 단위 정밀 배치)로 재조립.

한계:

- 줄 자체가 휘어진(제본 근처 곡면) 스캔은 선형 드리프트 모델로 부족할 수
  있음 — 필요 시 leptonica식 disparity mesh로 확장할 것.
- 본문 칼럼이 없는 페이지(장 제목, 헌사 등)는 콘텐츠를 캔버스 중앙에 배치함.
  왼쪽 정렬된 짧은 텍스트만 있는 페이지는 본문 그리드보다 안쪽으로 이동해
  보일 수 있음(중앙 배치가 제목·표지 페이지에 안전한 기본값이라 의도된 동작).
- 톤 보정은 본문 페이지에 `--knee` 값을(연한 인쇄면 잉크 밝기 기준으로 자동
  상향), 일러스트/희소 페이지에는 연필 음영 보호를 위해 더 부드러운
  니(190,235)를 적용.
- 러닝 헤더/푸터의 한글이 OCR에서 오인식된 극소수 페이지는 반복 키가 달라져
  텍스트 레이어에 남을 수 있음(읽기에는 보이지 않음).
