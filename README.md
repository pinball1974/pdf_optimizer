# pdfopt — 스캔한 책 PDF를 태블릿 독서용으로 최적화

자동급지 스캐너로 스캔한 책 PDF의 고질적인 문제를 해결하는 CLI 도구:

- **기울기 보정(디스큐)** — 급지 중 종이가 서서히 회전해 생기는 *페이지 내 각도
  드리프트*(상단과 하단 줄이 평행하지 않은 문제)까지 보정. 줄별 각도를
  `θ(y) = a + b·y`로 피팅한 뒤 픽셀별 변위 리매핑으로 모든 줄을 동시에 수평화.
- **고정폭 중앙 정렬** — 전 페이지의 본문 칼럼 폭을 측정해 최대 폭 + 좌우 5%
  여백의 통일 캔버스를 만들고, 각 페이지의 본문 칼럼 중심을 캔버스 중앙에 배치.
  홀/짝 페이지의 제본 여백 차이가 사라져 세로 스크롤 시 시선이 흔들리지 않음.
- **상하 여백 크롭** — 책 전체의 공통 상하 여백을 제거(모든 페이지 동일한 이동량
  적용 → 페이지 간 세로 리듬 유지). 페이지번호·각주는 원래 위치에 보존.
- **뒷비침 제거** — 배경에 가까운 밝은 회색만 흰색으로 눌러 뒷면 글자 비침 제거,
  글자 안티앨리어싱은 유지.
- **검색 가능한 OCR 레이어** — Apple Vision(macOS 내장, 로컬 처리)으로 한글을
  인식해 보이지 않는 텍스트 레이어 삽입. 반복 요소(러닝 헤더, 페이지 번호)는
  레이어에서 제외하고 본문 텍스트 블록만 넣음.
- **단락 복원 TXT 동시 저장** — OCR 결과에서 조판 기하(들여쓰기·행 간격·짧은
  마지막 행)로 단락 경계를 판정해, 문장/단락 내 강제 개행을 제거한
  `<원본이름>.txt`를 출력 PDF와 같은 폴더에 저장. 일러스트 페이지를 사이에 둔
  문단 연결, 구두점 경계 공백 복원, 오인식 숫자 노이즈 제거 포함 (`--no-txt`로
  생략 가능).
- 일러스트/표지/목차 페이지는 자동 감지해 기울기 보정을 건너뛰고 콘텐츠 기준
  중앙 배치.

## 설치

```bash
python3.13 -m venv venv
venv/bin/pip install -r requirements.txt
```

참고: venv에는 절대경로가 박혀 있어 프로젝트 폴더를 옮기면 깨진다. 폴더를
이동한 뒤에는 기존 venv를 지우고 위 명령으로 새로 만들 것. (iCloud Drive
안에서 쓸 경우에만 이름을 `venv.nosync`로 해서 동기화를 제외하면 된다.)

## 사용법

```bash
venv/bin/python -m pdfopt "책.pdf"                  # -> 책_optimized.pdf
venv/bin/python -m pdfopt "책.pdf" --pages 40-45    # 일부 페이지만 테스트
venv/bin/python -m pdfopt "책.pdf" --no-ocr --jpeg-quality 90
```

주요 옵션:

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o` | `<입력>_optimized.pdf` | 출력 경로 |
| `--pages` | 전체 | `5,10-12` 형식(1부터), 테스트용 부분 변환 |
| `--dpi` | 300 | 처리 해상도 |
| `--margin` | 0.05 | 본문 폭 대비 좌우 여백 비율 |
| `--jpeg-quality` | 82 | 출력 JPEG 품질 |
| `--no-ocr` | | OCR 텍스트 레이어 생략 |
| `--no-txt` | | 단락 복원 TXT 저장 생략 |
| `--no-clean` | | 뒷비침 제거 끄기 |
| `--knee` | `150,205` | 뒷비침 제거 강도(회색 레벨 k0,k1) |
| `--workers` | 코어-2 | 병렬 프로세스 수 |

분석 결과는 `<입력>.analysis.json`에 캐시되어 재실행 시 1차 패스를 건너뜀.

## 동작 원리

1. **분석 패스 (150dpi)** — 페이지마다 텍스트 라인을 검출해 본문 칼럼
   폭·위치, 줄별 각도, 잉크 영역을 기록.
2. **전역 통계** — 본문 최대 폭(고정폭 기준), 책 전체 공통 상하 콘텐츠 경계를
   산출해 통일 캔버스 크기 결정.
3. **변환 패스 (300dpi)** — 디스큐 → 톤 보정 → 캔버스 배치 → JPEG 인코딩 →
   Vision OCR. 페이지 병렬 처리.
4. **PDF 조립** — 페이지 이미지 + 보이지 않는 텍스트 레이어(`render_mode=3`,
   내장 한국어 폰트)로 재조립.

한계:

- 줄 자체가 휘어진(제본 근처 곡면) 스캔은 선형 드리프트 모델로 부족할 수
  있음 — 필요 시 leptonica식 disparity mesh로 확장할 것.
- 본문 칼럼이 없는 페이지(장 제목, 헌사 등)는 콘텐츠를 캔버스 중앙에 배치함.
  왼쪽 정렬된 짧은 텍스트만 있는 페이지는 본문 그리드보다 안쪽으로 이동해
  보일 수 있음(중앙 배치가 제목·표지 페이지에 안전한 기본값이라 의도된 동작).
- 톤 보정은 본문 페이지에 `--knee` 값을, 일러스트/희소 페이지에는 연필 음영
  보호를 위해 더 부드러운 니(190,235)를 자동 적용.
